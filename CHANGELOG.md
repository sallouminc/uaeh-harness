## [1.0.0] - 2026-11-10

### Added / Añadido

- `uaeh-harness` 0.1.0, layer 2 (verification harness). Hooks that block, in exec form: text-layer git guard (`guardia-git.js`, `onFailure: block`), read-only lock for reviewers with an identity gate (`solo-lectura.js` + `_identidad.js` + `candados.json`: it applies only to the agents listed there and exits silently anywhere else), integrity seal around every reviewer run (`uaeh-integridad.cjs` on `SubagentStart`/`SubagentStop`), closing guard (`uaeh-guardia-cierre.js`: commit, reviewer and stop) and a session-start line that reports a missing or outdated git guard.\
  `uaeh-harness` 0.1.0, capa 2 (arnés de verificación). Hooks que bloquean, en forma exec: guarda de git por texto (`guardia-git.js`, `onFailure: block`), candado de solo lectura para revisores con compuerta por identidad (`solo-lectura.js` + `_identidad.js` + `candados.json`: solo aplica a los agentes listados ahí y sale en silencio en cualquier otro sitio), sello de integridad alrededor de cada revisor (`uaeh-integridad.cjs` en `SubagentStart`/`SubagentStop`), guardia de cierre (`uaeh-guardia-cierre.js`: commit, revisor y cierre) y una línea de inicio de sesión que avisa si la guarda de git falta o está desactualizada.
- `uaeh-harness` git layer: the 19 global git-hook dispatchers plus `guardia-commit.cjs`, installed to a fixed-path mirror (`UAEH_HOME/estable/uaeh-harness/`) by `instalar.cjs git-guard`, which smoke-tests the guard in a temporary repository before setting the global `core.hooksPath` and never overwrites a foreign one (`--quitar` undoes it).\

- `uaeh-harness` libraries: `lib/config.cjs` (single user configuration with defaults, `UAEH_*` overrides, validation with warnings, commit policy, configurable whitelist) and `lib/runner.cjs` (platform detection, WSL/Linux argv builder with timeouts, `/mnt` path conversion, process execution without a shell).\

- Layer 3, Linux engine (`plugins/uaeh-harness/wsl/`): `herramientas.json` holds only pins (versions, the sha256 of every download taken from the project's official sums file, image digests, the Docker key fingerprint, publication dates checked against the «14 days or older» rule). `instalar.sh` reads them (no version is hard-coded in any script), takes the user from `UAEH_USER`, `SUDO_USER` or uid 1000 (never root), refuses anything but Ubuntu 24.04 x86_64, pulls the sandbox images by digest, installs gitleaks' default configuration (formerly a separate script), labels semgrep rules with their real download date and keeps healthy rules unless `UAEH_REGLAS_NUEVAS=1`; it records what it installed in `/opt/uaeh/instalado.json`. `UAEH_SKIP_DOCKER=1` uses an existing Docker and `UAEH_SOLO_ESCANERES=1` installs the scanners only. `instalar-bin.sh` copies the sandbox programs and writes `/opt/uaeh/uaeh.conf` (runs folder `UAEH_BASE` and user `UAEH_USER`), the only configuration those programs read; the runs folder must be absolute, at least three levels deep and under `/mnt`, `/srv` or `/home/<user>`. Both installers have a `--comprobar` mode that checks without root and writes nothing. `uaeh-sandbox`, `uaeh-promover` and `uaeh-validar` read `uaeh.conf` (owned by root, not writable by others, known keys only, values re-validated). Self-tests exit 77 (skipped) when layer 3, Docker or the network is missing.\
