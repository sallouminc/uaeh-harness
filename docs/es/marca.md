# Identidad visual de UAEH

[English](../en/marca.md) · [Índice](README.md)

## Nombre y significado

UAEH significa **Universal Agentic Engineering Harness**. Este es el único descriptor del logotipo: no se añade eslogan. Mantener el nombre completo en inglés también en piezas en español. La U angular alude a una estructura que sostiene el trabajo; sus pliegues representan método, verificación y controles especializados. No implica certificación ni seguridad absoluta.

## Logotipo e icono

![Icono UAEH](../../assets/brand/uaeh-icon-256.png)

El icono oficial es cuadrado, con fondo carbón incluido. Usar el PNG de 512 px en ambos plugins, idéntico byte a byte. El archivo maestro es raster: no se entrega como vector ni tiene transparencia. No reconstruir el símbolo a partir del tablero ilustrativo.

En el conjunto con nombre, situar UAEH en mayúsculas y debajo Universal Agentic / Engineering Harness en dos líneas. Usar el símbolo solo cuando el espacio no permita leer el nombre completo. Los nombres técnicos se mantienen como uaeh-kit y uaeh-harness.

## Color

| Color | HEX | Uso |
|---|---|---|
| Carbón | #20211F | Fondo principal y texto sobre superficies claras |
| Marfil | #ECE6D6 | Nombre, cuerpo y superficies claras |
| Lima | #B7EB42 | Acento del símbolo y detalles puntuales |
| Gris | #A7AAA2 | Información secundaria sobre carbón |

Los valores HEX son la referencia para superficies nuevas; la imagen raster conserva el acabado de la propuesta aprobada. Usar carbón sobre lima; evitar texto lima sobre marfil. No usar el verde de marca como prueba de que una revisión pasó: el estado debe escribirse.

## Tipografía

Bahnschrift para titulares y el nombre; Segoe UI para lectura; Consolas para identificadores técnicos. Las fuentes no se redistribuyen: se requiere una instalación con licencia. Como alternativa multiplataforma, usar una sans serif disponible y mantener jerarquía y proporciones; no estirar las letras para imitar otra fuente. La guía PDF incorpora los subconjuntos necesarios para su lectura.

## Espacio y tamaños

Mantener libre alrededor del conjunto una distancia mínima equivalente a un cuarto del ancho del símbolo visible. Conservar el margen integrado del icono cuadrado: no recortar. Mínimo recomendado: 32 px para el icono; 320 px para el conjunto con nombre completo; descriptor mínimo 14 px en pantalla. Por debajo de ese ancho, usar solo el icono y un nombre accesible.

## Aplicaciones y usos incorrectos

Los dos plugins comparten el mismo icono; se distinguen por su nombre. En fondos claros conservar el recuadro carbón. Usar superficies planas, buen espacio y diagonales del símbolo como detalle ocasional. No girar, deformar, recolorear, añadir sombras, añadir eslóganes ni combinar el símbolo con sellos de aprobación. No reducir el nombre completo hasta hacerlo ilegible. El tablero es una referencia de dirección visual; los PNG oficiales son la fuente para implementación.
