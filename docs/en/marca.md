# UAEH visual identity

[Español](../es/marca.md) · [Index](README.md)

## Name and meaning

UAEH stands for **Universal Agentic Engineering Harness**. This is the logo's only descriptor: do not add a slogan. Keep the full name in English, including in Spanish materials. The angular U suggests a structure supporting the work; its folds represent method, verification and specialized gates. It does not imply certification or absolute security.

## Logo and icon

![UAEH icon](../../assets/brand/uaeh-icon-256.png)

The official icon is square with a charcoal background included. Use the same 512 px PNG in both plugins, byte for byte. The master is raster, not vector, and has no transparency. Do not reconstruct the symbol from the illustrative overview board.

In the full lockup, set UAEH in capitals with Universal Agentic / Engineering Harness below on two lines. Use the symbol alone when the full name cannot be read. Technical plugin names remain uaeh-kit and uaeh-harness.

## Color

| Color | HEX | Use |
|---|---|---|
| Charcoal | #20211F | Main background and text on light surfaces |
| Ivory | #ECE6D6 | Name, body text and light surfaces |
| Lime | #B7EB42 | Symbol accent and occasional details |
| Gray | #A7AAA2 | Secondary information on charcoal |

HEX values are the reference for new surfaces; the raster image retains the approved concept's finish. Use charcoal text on lime; avoid lime text on ivory. Brand green is not evidence that a review passed: write the actual status.

## Typography

Bahnschrift for headings and the name; Segoe UI for reading; Consolas for technical identifiers. Fonts are not redistributed: use a licensed installation. For a cross-platform alternative, use an available sans serif while preserving hierarchy and proportions; do not stretch letters to imitate another font. The PDF embeds the subsets required for reading.

## Spacing and sizes

Keep clear space around the lockup equal to at least one quarter of the visible symbol's width. Preserve the square icon's built-in padding: do not crop. Recommended minimum: 32 px for the icon; 320 px for the full lockup; 14 px descriptor on screen. Below that width, use only the icon with an accessible name.

## Applications and incorrect use

Both plugins share an icon and are distinguished by name. Keep the charcoal tile on light backgrounds. Use flat surfaces, generous space and the symbol's diagonals as occasional details. Do not rotate, distort, recolor, add shadows, add slogans or combine the symbol with approval seals. Do not shrink the full name until unreadable. The board is an art-direction reference; official PNG files are the implementation source.
