# tools/manifiesto-importacion.txt — de dónde sale cada archivo de este repositorio.
#
# Los archivos de los plugins nacen en la configuración personal de su autor y se importan UNO POR UNO,
# nombrados aquí: nunca por carpeta ni por comodín (esa configuración también guarda credenciales,
# transcripciones y datos ajenos). Lo leen dos herramientas:
#   · tools/importar-lista-blanca.cjs  compara y copia lo que falta (en seco por defecto).
#   · tools/verificar-publicacion.cjs  todo archivo rastreado bajo plugins/ debe figurar aquí.
#
# Formato (texto plano; «#» abre un comentario; las líneas en blanco se ignoran):
#   [importados]          K/<ruta de origen> -> <ruta de destino dentro del repo>
#                         X/<ruta de origen> -> <ruta de destino dentro del repo>
#       K/  carpeta de configuración de Claude Code del usuario (CLAUDE_CONFIG_DIR o ~/.claude)
#       X/  carpeta de configuración de Codex del usuario (CODEX_HOME o ~/.codex)
#       El destino se edita después de importar (limpieza, traducción, rutas): por eso importar
#       nunca pisa un destino existente sin --forzar.
#   [nuevos]              una ruta del repo por línea: archivos escritos aquí, sin origen externo.
#   [grandes-permitidos]  una ruta del repo por línea: archivos de más de 200 KB admitidos a propósito.
#   [terceros]            una carpeta plugins/<plugin>/vendor/<nombre> por línea: código de terceros copiado de su
#                         repositorio público. Su procedencia no vive aquí sino en su UPSTREAM.json (origen, licencia,
#                         commit y la huella de cada archivo); verificar-publicacion comprueba esas huellas.
# Todas las rutas son relativas, con «/» y sin «..».
